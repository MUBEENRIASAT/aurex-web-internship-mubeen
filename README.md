## Task Description
Enhanced the Week 2 portfolio by applying advanced CSS techniques: CSS
custom properties (variables) for a consistent color and design system,
CSS Grid with `auto-fit`/`minmax` for a fully responsive skills section,
and keyframe animations with hover transitions to make the page feel more

and gold color scheme for a cleaner, more professional look.

## Technologies Used
- HTML5
- CSS3 (Grid, Flexbox, Custom Properties, Keyframe Animations, Transitions)
- Git
- GitHub
- GitHub Pages (deployment)

## CSS Features & Layout Techniques Implemented
- **CSS Variables** (`:root`) for colors (navy, gold, white) so the theme
  can be updated from one place
- **CSS Grid** for the skills section using `repeat(auto-fit, minmax(140px, 1fr))`,
  automatically adjusting the number of columns based on screen width
- **CSS Grid** for the overall page layout on desktop (sidebar nav + main
  content), switching to a stacked layout on mobile via media query
- **Flexbox** for the navigation bar and contact form alignment
- **Keyframe animation** (`@keyframes fadeIn`) so each section fades in
  smoothly on page load
- **Transitions** on hover states — nav links, skill chips, buttons, and
  panel cards all have smooth hover effects

## Project Description

This project is a JavaScript Task Management Application developed as part of the AUREX Full-Stack Engineering Internship.

The application allows users to create, edit, delete, complete, and filter tasks. Tasks are stored in the browser using localStorage so that they remain available after refreshing the page.


## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript
- DOM Manipulation
- Browser localStorage


## Features Implemented

- Add task
- Edit task
- Delete task
- Mark task as complete
- Filter tasks
- Form validation
- Save tasks in localStorage
- Retrieve tasks after page refresh
- Update stored tasks
- Remove stored tasks
- Responsive interface

## Challenges Faced

One challenge was understanding how to store JavaScript objects inside localStorage.

localStorage stores data as strings, so JSON.stringify() was used to convert the tasks array into a string before saving it.

JSON.parse() was then used to convert the stored string back into JavaScript data when the application loads.


## What I Learned

During Week 4, I learned the fundamentals of JavaScript and how JavaScript can interact with HTML through the DOM.

I also learned how to handle user events, validate form input, dynamically create elements, and persist application data using browser localStorage.
