# aurex-web-internship-mubeen
Week 1 task for AUREX Internship- Personal Profile page built with semantic HTML5
Intern Name: Mubeen
Domain: Full-Stack Web Development
Week: Week 1 — Development Setup + Git/GitHub Fundamentals + HTML5 Basics
## Task Description
Built a Personal Profile / Developer Introduction webpage (`index.html`) using
pure semantic HTML5, with no CSS styling as required by the Week 1 strict rule.
The page includes Header, Navigation, About Me, Skills, Education, Experience,
Contact Form, and Footer sections.
## Technologies Used
- HTML5
- Git
- GitHub
- ## How to Run Locally
1. Clone the repository:
   ```
   git clone https://github.com/<your-username>/aurex-web-internship-mubeen.git
   ```
2. Navigate into the project folder.
3. Open `index.html` directly in any web browser (double-click, or right-click → Open With → Browser).

No build steps or dependencies are required for Week 1.

## Key Learnings
- Practiced structuring an HTML document using semantic tags (`<header>`, `<nav>`,
  `<main>`, `<section>`, `<article>`, `<footer>`) instead of generic `<div>`s.
- Reinforced proper heading hierarchy (h1 → h2 → h3) for accessibility and SEO.
- Practiced accessible form design using `<label>` elements tied to inputs via `for`/`id`.
- Set up Git version control workflow: `git init`, `git add`, `git commit`, `git push`.
